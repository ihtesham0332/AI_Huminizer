# Current Features

## 1. Core Humanization
*   Accepts raw text and processes it through a LangGraph workflow.
*   Supports three rewrite strengths: Ninja (Light), Balanced (Medium), Ghost (Aggressive).

## 2. Parallel Candidate Generation
*   Generates multiple rewrite candidates concurrently.

## 3. Interactive Sentence Editing
*   Allows users to send individual sentences for specific rewrites via `/api/v1/sentence`.

## 4. UI / UX
*   Next.js dashboard with a premium Obsidian Glass theme.
*   SEO-optimized Landing Page.
*   Chrome Extension for in-browser rewriting.
*   Discord bot for community usage.

## 5. Security & Billing
*   Google OAuth integration.
*   Stripe Checkout integration for the $19/mo "Pro" tier.
