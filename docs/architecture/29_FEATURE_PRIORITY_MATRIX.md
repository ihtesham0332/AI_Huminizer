# 29. FEATURE PRIORITY MATRIX

We use a standard P0 (Must Have) to P4 (Future R&D) prioritization matrix to guide development.

## P0: Core MVP (Launch Blockers)
*   LangGraph Orchestrator
*   Fact & Citation Guardians (Protection Engine)
*   Quality Critic (Verification)
*   Selective Rewriting & Cost Controller
*   Model Router
*   Basic React UI with Diff Viewer

## P1: Strong Differentiators (Fast Follow)
*   Personal Writing DNA
*   Explainable Changes (The "Why" panel)
*   Smart Cost Estimation UI
*   Document Intelligence (Parsing structure)

## P2: Premium Features
*   Plagiarism/Similarity detection
*   Batch processing
*   API access and MCP Server
*   Advanced Academic/Thesis mode

## P3: Enterprise Features
*   Team workspaces
*   Brand Voice and Terminology Guide
*   SSO & Audit Logs

## P4: Future R&D
*   Locally hosted privacy models (Llama 3 on-prem).
*   Fine-tuned models specifically for the Generator step to reduce latency.
